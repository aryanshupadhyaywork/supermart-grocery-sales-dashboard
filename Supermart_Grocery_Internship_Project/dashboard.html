Project Scope & Method

This project answers the four business objectives in the supplied SapphireIQ brief: overall sales performance, product performance, profit/discount relationship, and geographic performance. Data was loaded from the provided CSV, order dates normalized, and sales/profit aggregated by category, region, month, sub-category and discount level. No external data was added.

Important data limitation: the dataset lists every State as Tamil Nadu, so state-level comparison is not meaningful in this file. City/region comparisons should be interpreted within the supplied data. Discount is a rate; summing discount values is not a useful business KPI, so average discount is shown instead.
